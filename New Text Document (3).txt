COMMAND LINE PROMPT - DEMO ( I will train for 2000 episodes in demo video, else video will be bigger in size)
LOCATE YOUR GAME.EXE
Step1: Train your model 

python train_rl.py --model <name> --episodes <amount>  

Once trained, your model will be saved in ./models. 

Step 2: Further train your model 
-- launch game again or use the already launched exe. 
python retrain.py --model <name> --episodes <amount> 
OR Step 2: Further train your model using multiple instances 
-- no need to launch game manually. 
python autorun.py --model <name> --episodes <amount>

Step3: Test your model using command
-- launch game
python test_rl.py --model <name> --episodes <amount>  // lets do good model.  

OPTIONAL: If you want to see live Observation, run python obsviewer.py in a different terminal.
